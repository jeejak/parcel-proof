ParcelProof by Jeejak

Indonesian online sellers lose Shopee and TikTok disputes because their packing photos turn out to be useless: too dark, the label cut off, the box not shown sealed. Our app JejakPaket records the photos; this prototype checks, right after packing, whether they would hold up.

Two checks run side by side. The basic check measures brightness, sharpness and the shipping barcode in Go, with no model and no cost. The Gemini check reads the whole photo set and reports what it sees in a fixed schema. In both, our server decides the verdict; the model never writes text a seller reads, and is never told which tracking number to expect.

Measured, not claimed

Gemini 3.5 Flash-Lite on 64 staged parcels (37 labelled weak by a person), prompt 2026-10-07.1, before any seller sees a verdict. The targets were set before this run.
